# Frontend Inertia React Rules

## Inertia Navigation and Form Submissions
Use Inertia `<Link>`, `useForm`, or `router` from `@inertiajs/react` for all page navigation, modal forms, and mutations. Never use raw `fetch()`, `axios`, or `window.location.reload()` for application state changes.

## Bahasa Indonesia UI Copy and Brand Assets
Write all UI labels, empty states, and alerts directly in Bahasa Indonesia. Use `/hajirin_icon.svg` for the brand logo asset across all pages and layouts.
